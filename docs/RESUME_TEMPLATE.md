## 3. STAR 详版（面试展开用）

### STAR-1｜多模态单据抽取：把"看起来能抽"做成"可审计地抽"
- **S**：间接采购 15% 合同/发票是扫描件，人工逐行录入与核对平均 8 分钟/组，金额/税率错漏后果严重。
- **T**：无 OCR 基础设施条件下搭可追溯抽取管线，字段准确率与成本可量化。
- **A**：DocumentRouter 按文本层比例 + 版式模板分流（native / scanned / hybrid）；数字 PDF 用 pdfplumber 表格+正则+算术校验；
  扫描件走 VLM + JSON Schema + Pydantic + repair loop；抽取同步产出归一化 bbox 供 PDF 抽屉高亮。
- **R**：237 份文档路由 native 213 / scanned 24；发票关键字段（发票号/价税合计/销方名称）准确率 **100%**（n=68）；
  native 抽取 p95 **46.14ms**；扫描件字段准确率与单票成本因离线 FakeLLM **未测**（诚实标注）。

### STAR-2｜规则引擎 + 混合检索：把"AI 建议"变成"可复现结论"
- **S**：采购申请描述不规范（"买 10 台办公电脑"），采购员平均 2.7 轮往返；纯 LLM 判定不可复现、不可审计。
- **T**：80% 判定由确定性规则完成，LLM 只补语义层，每条结论可溯源。
- **A**：声明式 JSONLogic 白名单 DSL（未声明算子显式报错）；三路检索（pg_trgm 词法 / 精确名与别名 / 规格桶结构化）+ RRF；
  语义消歧只补"必须由人确认"的字段；verdict 由规则引擎算出，LLM schema 无 verdict 字段。
- **R**：120 条 PR 上 verdict 一致率 **100%**、findings micro F1 **1.0**（tp=112）、检索 top-1 **100%**（105 样本）；
  60/120 用例产生补丁（共 120 条）；向量 leg 与 recall@5 因无 embedding 端点**未做**（ADR-020）。

### STAR-3｜三单匹配：确定性算法 + 容差模型 + HITL
- **S**：合同/PO/发票在金额、税率、数量、分批、交期上易错，人工逐行核对易漏，挂起原因要向审计解释。
- **T**：行级对齐 + 容差判定 + 分批核销，每条结论可追溯到规则与原件。
- **A**：三级对齐构造得分矩阵，匈牙利做全局一对一指派（贪心作消融基线）；五类容差表落库可配；
  `ordered/received/invoiced/remaining` 状态机支持分批开票与尾差平账；HITL 中断前不写会计事实。
- **R**：80 组上 overall **100%**、6 类差异 micro F1 **1.0**（tp=60，fp=0）、行对齐 F1 **1.0**；
  匈牙利优势由冲突矩阵单测证明（种子每组仅 1 行，指标与贪心相同）；端到端 P95 **未测**。

### STAR-4｜可观测与成本治理（工程成熟度）
- **S**：LLM 应用最常被质疑"不可控、不可算账"。
- **T**：每次调用可记账、每次运行可回放、成本可归因。
- **A**：自写网关（路由/降级/重试/缓存/结构化 repair）；`llm_call` 记录 tokens/成本/延迟/缓存；
  `run_event` 单调 seq 支持 `?after_seq=` 断线回放；提供 Run 中心 + 可观测页（节点时间线/LLM 记账/评测基线）。
- **R**：真实模型联调验证 M2 复核成功（一次调用 tokens 1658→2662，记账成本 ¥0.0131）；
  离线全量基线成本 ¥0（FakeLLM），真实成本/缓存命中率待全量回填（面试主动说明）。

## 5. 面试口径（必须主动说明，避免被追问翻车）

1. 数据全部**合成**（seed=42 自建工厂），指标是在合成 gold 上的**回归一致性**，不是真实业务精度。
2. M1/M3 的 gold 与实现**同源**；真实精度需要在真实票据/真实 PR 上重评。
3. 当前评测为**离线 FakeLLM**：M2 的 LLM 复核、扫描件 VLM、真实成本/延迟/缓存命中率需接入模型后回填；
   已用真实模型验证单次 M2 复核闭环（成本约 ¥0.01/次），但未跑全量。
4. 向量检索 leg（embedding）未接；M2 无专家标注 gold（维度 MAE/κ 未测）；M3 已支持多发票顺序核销（单次 ≤20 张，双发票 e2e 已验证）。
5. LangGraph 使用进程内 MemorySaver，多副本需换 Postgres checkpointer（已在部署文档标注）。
6. 人工基线 8min/组是面板估算（estimated），非实测。
